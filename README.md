# Worldline

European payment and digital services company providing REST APIs for payment processing, acquiring, digital banking services, open banking, identity and authentication, and merchant account management.

**Website:** https://worldline.com/  
**Developer Portal:** https://developer.worldline.com/en/home  
**Financial Services Portal:** https://financial-services.developer.worldline.com/home

## APIs

| API | Description | Documentation |
|-----|-------------|---------------|
| Connect (Global Collect) | Enterprise global online payment processing | https://docs.connect.worldline-solutions.com/ |
| Direct (Global Online Pay) | SMB online payments with 40+ APMs | https://docs.direct.worldline-solutions.com/ |
| Acquiring | REST API for PSPs and Payment Facilitators | https://docs.acquiring.worldline-solutions.com/ |
| Financial Services Issuing | Modular card management for issuers | https://financial-services.developer.worldline.com/issuing/documentation |
| Financial Services Acquiring | Smart acquiring for financial institutions | https://financial-services.developer.worldline.com/acquiring/documentation |
| Open Banking | PSD2 connectivity to 3,500+ European banks | https://financial-services.developer.worldline.com/open-banking/documentation |
| SmartPOS | Android payment terminal app development | https://docs.smartpos.worldline-solutions.com/smartpos/ |
| Identity and Authentication | FIDO, OAuth2, 3DS security APIs | https://financial-services.developer.worldline.com/api-catalogue |
